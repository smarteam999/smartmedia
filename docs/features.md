# 功能特性 (Features)

## 已支持功能

- [x] **多数据源支持**
    - [x] Openlist 数据源接入
    - [x] 123-API 数据源接入
    - [x] 支持数据源内容浏览
- [x] **STRM 管理**
    - [x] 批量生成 STRM 文件
    - [x] 自定义 STRM 文件模板
- [x] **自动化任务**
    - [x] 定时自动生成/更新 STRM 文件
- [x] **Web 管理界面**
    - [x] 可视化配置管理
    - [x] 任务状态监控

## 待开发规划 (Roadmap)

> 欢迎提交 Issue 建议新功能。

- [ ] 更多网盘挂载工具支持 (Alist, CD2 等)
- [ ] 刮削器兼容性优化 (Emby, Plex, Jellyfin)
- [ ] 消息通知推送 (Telegram, WeChat, etc.)
